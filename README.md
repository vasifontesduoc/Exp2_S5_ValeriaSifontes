# Exp2_S5_ValeriaSifontes
# Programación de bases de datos
Este proyecto implementa un proceso en PL/SQL para calcular el aporte SBIF de los avances y súper avances realizados por los clientes durante un año determinado, utilizando una variable bind para parametrizar el periodo.

El bloque anónimo trabaja con cursores explícitos, registros PL/SQL, VARRAY y manejo de excepciones para generar información detallada y resumida, almacenándola en las tablas DETALLE_APORTE_SBIF y RESUMEN_APORTE_SBIF. Además, el proceso incluye truncado de tablas y confirmación de transacciones para asegurar una ejecución correcta y repetible.
